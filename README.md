# ⌨️ Corne v4.1 (46-key) QMK Custom Configuration

이 프로젝트는 **Corne v4.1 (RP2040)** 분할 키보드를 위한 커스텀 QMK 펌웨어 설정 저장소입니다. 기존 설정을 최적화하여 완벽한 좌우 대칭 엄지 모디파이어 구조와 효율적인 4레이어(RAW 제외) 구성을 구현했습니다.

## 🛠 Hardware Info
- **Model:** Corne v4.1 (Standard, 46-key version)
- **MCU:** RP2040 (Integrated)
- **Layout:** 3x6_3 with 2 extra inner keys per side (`LAYOUT_split_3x6_3_ex2`)

## ⌨️ Visual Layout
 
### 1. Default Layer (`_DEFAULT`)
기본 타이핑 레이어입니다. 알파 키들의 타건 속도 족쇄였던 검지 Shift(`F_SFT`, `J_SFT`)를 완전히 일반 키(`KC_F`, `KC_J`)로 원복하여, 초고속 타건 시의 오타와 입력 병목을 원천 봉쇄했습니다. 
대신 **양쪽 엄지 안쪽 키**에 오판정이 없는 순수한 dedicated Shift 키(`KC_LSFT` / `KC_RSFT`)를 배치하고, 기존의 `_FUNC` 진입용 모디파이어 키와 `Enter`를 결합한 `ENT_FUNC` 키를 **양손 검지 안쪽 홈로우 영역**으로 대칭 이동시켜 입력 속도와 타이핑 안정성을 극한으로 끌어올렸습니다.
 
```text
┌───────┬───────┬───────┬───────┬───────┬───────┬───────┐       ┌───────┬───────┬───────┬───────┬───────┬───────┬───────┐
│  ESC  │   Q   │   W   │   E   │   R   │   T   │  TAB  │       │  TAB  │   Y   │   U   │   I   │   O   │   P   │ BSPC  │
├───────┼───────┼───────┼───────┼───────┼───────┼───────┤       ├───────┼───────┼───────┼───────┼───────┼───────┼───────┤
│ LCTL  │   A   │ S(G)  │ D(A)  │ F(C)  │   G   │ ENT(F)│       │ ENT(F)│   H   │ J(C)  │ K(A)  │ L(G)  │   ;   │   '   │
├───────┼───────┼───────┼───────┼───────┼───────┼───────┘       └───────┼───────┼───────┼───────┼───────┼───────┼───────┤
│ LSFT  │   Z   │   X   │   C   │   V   │   B   │                       │   N   │   M   │   ,   │   .   │   /   │ RSFT  │
└───────┴───────┴───────┼───────┼───────┼───────┤                       ├───────┼───────┼───────┼───────┴───────┴───────┘
                        │ TAB(N)│ SPC(N)│ LSFT  │                       │ RSFT  │ SPC(N)│ TAB(N)│
                        └───────┴───────┴───────┘                       └───────┴───────┴───────┘
```
*(G=GUI, A=Alt, C=Ctrl, S=Shift, TAB=Tab Key, ENT(F)=Enter hold for Func Layer, TAB(N)=Tab hold for Num Layer, SPC(N)=Space hold for Navi, LSFT/RSFT=Pure Left/Right Shift)*
 
### 2. Navigation Layer (`_NAV`)
방향키와 마우스 제어 레이어입니다. (**양쪽 엄지 가운데** 키 홀드 시 진입)
 
```text
┌───────┬───────┬───────┬───────┬───────┬───────┬───────┐       ┌───────┬───────┬───────┬───────┬───────┬───────┬───────┐
│       │  TAB  │ WH_L  │ WH_D  │ WH_U  │ WH_R  │ TG(R) │       │ TG(R) │ HOME  │ PGUP  │ PGDN  │  END  │       │       │
├───────┼───────┼───────┼───────┼───────┼───────┼───────┤       ├───────┼───────┼───────┼───────┼───────┼───────┼───────┤
│ ACL0  │       │ MS_L  │ MS_D  │ MS_U  │ MS_R  │       │       │       │ LEFT  │ DOWN  │  UP   │ RGHT  │       │       │
├───────┼───────┼───────┼───────┼───────┼───────┼───────┘       └───────┼───────┼───────┼───────┼───────┼───────┼───────┤
│ ACL2  │       │ BTN1  │ BTN3  │ BTN2  │       │                       │       │ BSPC  │  DEL  │       │       │       │
└───────┴───────┴───────┼───────┼───────┼───────┤                       ├───────┼───────┼───────┼───────┴───────┴───────┘
                        │       │       │       │                       │       │       │       │
                        └───────┴───────┴───────┘                       └───────┴───────┴───────┘
```
*(ACL0/2=마우스 가속 속도 0/2, WH_L/D/U/R=마우스 휠 좌/하/상/우, MS_L/D/U/R=마우스 커서 이동 좌/하/상/우, BTN1/3/2=마우스 좌클릭/휠클릭/우클릭, BSPC=Backspace, DEL=Delete, TG(R)=RAW Toggle)*
 
### 3. Number & Symbol Layer (`_NUM`)
숫자 입력 및 특수 기호 통합 레이어입니다. (**양쪽 엄지 가장 바깥쪽** `MO(_NUM)` 키 홀드 시 진입)
왼손 아랫줄에 직관적인 괄호 고속도로(`[ ] ( ) \` on `Z, X, C, V, B`)를 구축하고, **왼손 검지 안쪽 확장 열(Row 0, Row 1)에 `{`와 `}` 중괄호 쌍을 직관적으로 배치**했습니다. 오른손으로 `MO(_NUM)`을 누른 상태에서 왼손이 놀지 않도록 **왼손 엄지 3개 영역에 `_`, `+`, `|` 기호를 배치**하고, **오른손 검지 아래(`=`)와 엄지 안쪽(`%`)에 계산용 특수기호를 추가**하여 오른손 영역은 표준 텐키 패드와 연산 전용 패널을 결합했습니다.
 
```text
┌───────┬───────┬───────┬───────┬───────┬───────┬───────┐       ┌───────┬───────┬───────┬───────┬───────┬───────┬───────┐
│   `   │   !   │   @   │   #   │   $   │   %   │   {   │       │       │   /   │   7   │   8   │   9   │   -   │   ~   │
├───────┼───────┼───────┼───────┼───────┼───────┼───────┤       ├───────┼───────┼───────┼───────┼───────┼───────┼───────┤
│       │   ^   │   &   │   *   │   -   │   =   │   }   │       │       │   *   │   4   │   5   │   6   │   +   │       │
├───────┼───────┼───────┼───────┼───────┼───────┼───────┘       └───────┼───────┼───────┼───────┼───────┼───────┼───────┤
│ LSFT  │   [   │   ]   │   (   │   )   │   \   │                       │   =   │   1   │   2   │   3   │   ?   │       │
└───────┴───────┴───────┼───────┼───────┼───────┤                       ├───────┼───────┼───────┼───────┴───────┴───────┘
                        │   _   │   +   │   |   │                       │   %   │   0   │   .   │
                        └───────┴───────┴───────┘                       └───────┴───────┴───────┘
```
 
### 4. Function Layer (`_FUNC`)
기능 키 레이어입니다. (**양손 검지 안쪽 홈로우의 `MO(_FUNC)`** 키 홀드 시 진입)
인지 부하를 줄이기 위해 왼손과 오른손에 `F1`~`F12` 기능 키를 완벽 대칭 거울상(Mirroring) 구조로 배치했습니다.
추가로 왼손 Q/A 자리에 볼륨 올림/내림(VOL+/VOL-)을, 오른손 P/; 자리에 화면 캡처 및 Shift 화면 캡처(PSCR / S(PSCR))를 배치하여 편의성을 강화했습니다.
 
```text
┌───────┬───────┬───────┬───────┬───────┬───────┬───────┐       ┌───────┬───────┬───────┬───────┬───────┬───────┬───────┐
│       │ VOL+  │  F9   │  F8   │  F7   │  F12  │       │       │       │  F12  │  F7   │  F8   │  F9   │ PSCR  │       │
├───────┼───────┼───────┼───────┼───────┼───────┼───────┤       ├───────┼───────┼───────┼───────┼───────┼───────┼───────┤
│       │ VOL-  │  F6   │  F5   │  F4   │  F11  │       │       │       │  F11  │  F4   │  F5   │  F6   │S(PSCR)│       │
├───────┼───────┼───────┼───────┼───────┼───────┼───────┘       └───────┼───────┼───────┼───────┼───────┼───────┼───────┤
│       │       │  F3   │  F2   │  F1   │  F10  │                       │  F10  │  F1   │  F2   │  F3   │       │       │
└───────┴───────┴───────┼───────┼───────┼───────┤                       ├───────┼───────┼───────┼───────┴───────┴───────┘
                        │       │       │       │                       │       │       │       │
                        └───────┴───────┴───────┘                       └───────┴───────┴───────┘
```
 
### 5. RAW Layer (`_RAW`)
홈로우 모드가 일시 정지된 일반 키보드 레이어입니다. 게임 실행이나 빠른 연속 타이핑 등 단일 키 입력 처리가 요구될 때 유용합니다. (`TG(_RAW)` 키로 토글하여 활성화/비활성화)
안정적인 대칭을 위해 **양손 검지 안쪽 최상단 열(Row 0)**에 대칭 배치하였습니다.

├───────┼───────┼───────┼───────┼───────┼───────┼───────┘       └───────┼───────┼───────┼───────┼───────┼───────┼───────┤
│ LSFT  │   Z   │   X   │   C   │   V   │   B   │                       │   N   │   M   │   ,   │   .   │   /   │ RSFT  │

## 🚀 Quick Start (NixOS)

### 1. 동기화 (최초 1회 실행)
저장소의 설정을 `qmk_firmware` 폴더 내의 Corne 키맵 위치로 심볼릭 링크를 설정합니다.

```bash
# 기존 디렉토리가 존재한다면 삭제 (또는 백업)
rm -rf ~/qmk_firmware/keyboards/crkbd/keymaps/yongminari

# 올바른 경로로 심볼릭 링크 설정
ln -s /home/yongminari/workspace/qmk_split_keymap/keymaps/yongminari ~/qmk_firmware/keyboards/crkbd/keymaps/yongminari
```

### 2. Build (펌웨어 컴파일)
저장소 루트의 빌드 헬퍼 스크립트를 사용하여 펌웨어를 빌드합니다.

```bash
qmk compile -kb crkbd/rev4_1/standard -km yongminari --clean
```

### 3. Flash (펌웨어 다운로드)
스플릿 키보드의 부트로더 모드(RPI-RP2)에 각각 연결한 뒤 플래시 헬퍼 스크립트를 사용하여 양쪽에 펌웨어를 다운로드합니다.
- **부트로더 진입 방법:**
  - **왼쪽:** `Q` 키를 누른 채 USB 연결
  - **오른쪽:** `P` 키를 누른 채 USB 연결

```bash
# 장치 이름(sdX1 등)은 lsblk 명령어는 필수 확인
sudo dd if=/home/yongminari/qmk_firmware/crkbd_rev4_1_standard_yongminari.uf2 of=/dev/sdX1 conv=fdatasync status=progress
```

## ⌨️ Keymap Features
- **Home Row Mods (GAC):** `S,D,F / J,K,L` 키에 GUI, Alt, Ctrl 적용 (오판정이 잦은 새끼손가락 `A` 및 `;`에서 모디를 완전히 배제하고, 안쪽으로 시프트).
- **Tapping Term:** 180ms 일괄 적용.
- **Tapping Optimizations:** 오작동 방지를 위해 `HOLD_ON_OTHER_KEY_PRESS_PER_KEY` 제거 및 `PERMISSIVE_HOLD` 적용.
- **Caps Word 더블탭 기능:** 외각 핑크색 Shift 키 및 **엄지 순수 Shift 키**(`KC_LSFT` / `KC_RSFT`)를 빠르게 **더블 탭**하여 Caps Word 상태를 즉시 활성화할 수 있습니다.
- **Layers:**
  - `_DEFAULT`: 기본 알파, GAC 홈로우 모드, 양손 엄지 순수 Shift 배치 구조.
  - `_NAV`: 방향키, 마우스 제어. **양쪽 엄지 가운데 키**(`SPC_NAV` / `LT(_NAV, KC_SPC)`) 홀드로 진입.
  - `_NUM`: 통합 숫자 & 특수 기호 레이어. **양쪽 엄지 가장 바깥쪽 키**(`TAB_NUM` / `LT(_NUM, KC_TAB)`) 홀드로 진입.
  - `_FUNC`: F1 ~ F12 기능 키. **양손 검지 안쪽 홈로우 키**(`MO(_FUNC)`) 홀드로 진입. 왼손 Q/A 자리에 볼륨 조절(VOL+/VOL-), 오른손 P/; 자리에 화면 캡처(PSCR/Shift PSCR)를 배치했습니다.
  - `_RAW`: 홈로우 정지 모드 (양손 검지 안쪽 최상단 Row 0 키로 토글).
- **Key Position Changes for Optimization (인체공학 및 타이핑 효율성 극대화):**
  - **엄지 순수 Shift 및 검지 안쪽 Enter 이식 (Ergonomic 최적화의 완성)**: 타이핑 흐름의 오타를 원천적으로 방지하고 Shift 반응을 극대화하기 위해, 양쪽 엄지 안쪽 키를 오판정 확률이 0%인 완전한 **순수 Shift 키 (`KC_LSFT`, `KC_RSFT`)**로 배정했습니다. 대신 기존 엄지에 숨겨져 있어 잘못 눌릴 위험이 컸던 `Enter` 키를 양손 검지 안쪽 홈로우의 명당자리에 **`ENT_FUNC` (`LT(_FUNC, KC_ENT)`)**로 배정하여, 탭하면 Enter가 전송되고 홀드하면 Func 레이어가 활성화되도록 완벽히 개선했습니다.
  - **_RAW 레이어 진입 키 대칭 배치**: `TG(_RAW)`는 양손 검지 안쪽 Row 0에 정교하게 나란히 대칭 배치하여 인지 피로를 최소화했습니다.
  - **알파 키 딜레이 원복 (`V`, `N`, `G`, `Comma`)**: 모든 알파 키들의 레이어 모디파이어 기능을 완전히 제거하여 일반 키로 지정, 고속 타이핑 시 딜레이와 오작동 원천 방지.
  - **대칭형 엄지 레이아웃 최적화**:
    - **가장 바깥쪽 (Outer)**: `Num/Sym` 통합 모디파이어 (`TAB_NUM` / `LT(_NUM, KC_TAB)` - 탭 시 Tab, 홀드 시 NUM 레이어)
    - **가운데 (Middle)**: `Navi` 모디파이어 (`SPC_NAV` / `LT(_NAV, KC_SPC)` - 탭 시 Space, 홀드 시 NAV 레이어)
    - **가장 안쪽 (Inner)**: `Shift` 모디파이어 (`KC_LSFT` / `KC_RSFT` - 오판정 제로 순수 Shift)
  - **기호 및 괄호 최적 배치 ("Shift-Pair Standard Optimization")**:
    - `[]`, `()`, `\` 괄호 고속도로: 왼손 아랫줄 `Z, X, C, V, B` 위치에 `[`, `]`, `(`, `)`, `\`를 나란히 배치하여, 손목 및 인지 피로를 최소화했습니다.
    - **`{}` 중괄호 직관적 배치 (검지 확장 영역)**: 기존에 Shift 조합(`Shift + [ / ]` -> `{ / }`)으로 입력해야 해서 타이핑 흐름을 끊고 비효율적이었던 중괄호 쌍을, `_NUM` 레이어의 왼쪽 검지 안쪽 확장 열(Inner Column) 위/아래 빈자리(`KC_LCBR` / `KC_RCBR`)에 배치했습니다. 이제 `_NUM` 레이어 진입 상태에서 별도의 Shift 입력 없이 가볍게 검지만 뻗어 `{`와 `}`를 즉시 초고속으로 입력할 수 있습니다.
    - **``` ` ``` 백틱 및 `~` 물결표 대칭 배치**: `_NUM` 레이어 진입 시 왼쪽 판 가장 바깥쪽 최상단(ESC 자리)에는 ``` ` ``` (백틱)을, 오른쪽 판 가장 바깥쪽 최상단(Backspace 자리)에는 `~` (물결표, `KC_TILD`)를 대칭 배치하여 직관성을 높였습니다.
    - **왼손 엄지 기호 배치 (`_`, `+`, `|`)**: 오른손의 `_NUM` 모디파이어 키를 눌러 진입할 때, 왼손 엄지의 세 개 키가 `_` (Underscore), `+` (Plus), `|` (Vertical Pipe)를 입력할 수 있도록 매핑하여 키 입력 효율과 연계성을 향상했습니다.
    - **오른손 계산기 패널 최적화 (`=`, `%` 추가)**: `_NUM` 레이어에서 오른손 검지 아래 열(기본 `n` 위치)에 `=` 기호를 배치하고, 오른손 엄지 안쪽 키(기본 `Enter` 위치)에 `%` 기호를 추가하여 오른손만으로 숫자와 필수 사칙연산 및 계산 관련 특수기호(`=`, `%`)를 모두 신속하게 입력할 수 있도록 편의성을 대폭 개선했습니다.
    - **마침표(`.`) 및 물음표(`?`) 입력 편의성 개선**: `_NUM` 레이어에서 자주 사용하는 마침표(`.`)를 오른쪽 엄지 바깥쪽 키(기본 `TAB_NUM` 자리)로 이동하고, 기존 마침표 자리에 물음표(`?`)를 배치하여 입력 동선을 효율화했습니다.
  - **F-키 미러링 최적화**: `F1`~`F12`를 좌우 대칭으로 설계하여 인지 편의성을 개선했습니다. (기존 왼손 Q열의 `TAB` 키는 삭제하여 기본 문자 입력으로 환원)
