# ⌨️ Corne v4.1 (46-key) QMK Custom Configuration

이 프로젝트는 **Corne v4.1 (RP2040)** 분할 키보드를 위한 커스텀 QMK 펌웨어 설정 저장소입니다. 양손 아우터 라인(최외각 열)을 완전히 비운 3x5+3 구조와 효율적인 4개 레이어(`_DEFAULT`, `_NAV`, `_NUM`, `_FUNC`) 구성을 구현했습니다.

## 🛠 Hardware Info
- **Model:** Corne v4.1 (Standard, 46-key version / 3x5+3 사용)
- **MCU:** RP2040 (Integrated)
- **Layout:** 3x6_3 with 2 extra inner keys per side (`LAYOUT_split_3x6_3_ex2`) - 양손 최외각 Column 0 제거

## ⌨️ Visual Layout
 
### 1. Default Layer (`_DEFAULT`)
기본 타이핑 레이어입니다. 양손 최외각 Column 0을 완전히 비워(`_______`) 3x5+3 인체공학적 배치를 완성했습니다.
- **Home Row Mods (GAC):** `S, D, F / J, K, L` 키에 GUI, Alt, Ctrl 배치.
- **Dedicated Thumb Shift:** 양쪽 엄지 안쪽 키에 오판정이 없는 `KC_LSFT` / `KC_RSFT` 전용 Shift 키 배치.
- **Dedicated Enter:** `_FUNC` 진입용 `ENT_FUNC` 키를 **양손 검지 안쪽 홈로우 영역**으로 대칭 이동.
 
```text

│   ·   │   Q   │   W   │   E   │   R   │   T   │  TAB  │       │  TAB  │   Y   │   U   │   I   │   O   │   P   │   ·   │
├───────┼───────┼───────┼───────┼───────┼───────┼───────┤       ├───────┼───────┼───────┼───────┼───────┼───────┼───────┤
```

### 2. Navigation Layer (`_NAV`)
방향키 및 마우스 제어 레이어입니다. (**양쪽 엄지 가운데** `SPC_NAV` 키 홀드 시 진입)
- `SPC_NAV` + `Q` 조합으로 **`ESC`** 입력.
- `SPC_NAV` + `V` 조합으로 **`Backspace`** 입력.
- **오른쪽 엄지 중간 키**: `KC_RALT` (한/영 전환)
- **오른쪽 엄지 바깥 키**: `KC_RCTL` (한자 변환)
 
```text
┌───────┬───────┬───────┬───────┬───────┬───────┬───────┐       ┌───────┬───────┬───────┬───────┬───────┬───────┬───────┐
│   ·   │  ESC  │ WH_L  │ WH_D  │ WH_U  │ WH_R  │   ·   │       │   ·   │ HOME  │ PGUP  │ PGDN  │  END  │   ·   │   ·   │
```

### 3. Number & Symbol Layer (`_NUM`)
숫자 입력 및 특수 기호 통합 레이어입니다. (**양쪽 엄지 가장 바깥쪽** `TAB_NUM` 키 홀드 시 진입)
- **중괄호(`{`, `}`)**: 왼쪽 안쪽 열 상단(`{` `KC_LCBR`) 및 중단(`}` `KC_RCBR`)
- **백틱(` ` `) & 틸드(`~`)**: 오른쪽 안쪽 열 상단 (`KC_GRV`, Shift와 조합 시 `~`)
- **작은따옴표(`'`) & 큰따옴표(`"`)**: 오른쪽 안쪽 열 중단 (`KC_QUOT`, Shift와 조합 시 `"`)
- **괄호 고속도로**: 왼손 아랫줄(`Z, X, C, V, B`)에 `[ ] ( ) \` 배치.

### 4. Function Layer (`_FUNC`)
기능 키 레이어입니다. (**양손 검지 안쪽 홈로우의 `MO(_FUNC)`** 키 홀드 시 진입)
- `F1`~`F12` 기능 키 좌우 대칭 미러링 구조.
- 왼손 `Q/A` 자리에 볼륨 조절(`VOL+`/`VOL-`), 오른손 `P/;` 자리에 화면 캡처(`PSCR`/`Shift PSCR`).

## 🚀 Quick Start (NixOS)

### 1. 동기화 (최초 1회 실행)
저장소의 설정을 `qmk_firmware` 폴더 내의 Corne 키맵 위치로 심볼릭 링크를 설정합니다.

```bash
# 기존 디렉토리가 존재한다면 삭제 (또는 백업)
rm -rf ~/qmk_firmware/keyboards/crkbd/keymaps/yongminari

# 올바른 경로로 심볼릭 링크 설정
ln -s /home/yongminari/workspace/qmk_split_keymap/keymaps/yongminari ~/qmk_firmware/keyboards/crkbd/keymaps/yongminari
```

### 2. Build (펌웨어 컴파일)
저장소 루트의 빌드 헬퍼 스크립트를 사용하여 펌웨어를 빌드합니다.

```bash
qmk compile -kb crkbd/rev4_1/standard -km yongminari --clean
```

### 3. Flash (펌웨어 다운로드)
스플릿 키보드의 부트로더 모드(RPI-RP2)에 각각 연결한 뒤 플래시 헬퍼 스크립트를 사용하여 양쪽에 펌웨어를 다운로드합니다.
- **부트로더 진입 방법:**
  - **왼쪽:** `Q` 키를 누른 채 USB 연결
  - **오른쪽:** `P` 키를 누른 채 USB 연결

```bash
# 장치 이름(sdX1 등)은 lsblk 명령어 필수 확인
sudo dd if=/home/yongminari/qmk_firmware/crkbd_rev4_1_standard_yongminari.uf2 of=/dev/sdX1 conv=fdatasync status=progress
```

## ⌨️ Keymap Features
- **3x5+3 구조 (양손 아우터 라인 완전 제거)**: 양손 최외각 Column 0을 전 레이어에 걸쳐 `_______`로 무효화하여 손가락 이동 동선을 단축하고 오입력을 방지했습니다.
- **Home Row Mods (GAC):** `S,D,F / J,K,L` 키에 GUI, Alt, Ctrl 적용. 윈도우 환경 호환성을 위해 좌우 홈로우 모두 Left Modifier를 사용합니다.
- **Tapping Term:** 180ms 일괄 적용.
- **Caps Word 더블탭 기능:** 양쪽 엄지 순수 Shift 키 (`KC_LSFT` / `KC_RSFT`)를 빠르게 더블 탭하여 Caps Word 활성화.
- **RAW Layer 완전 제거**: 사용하지 않는 RAW 레이어 및 토글 키를 완전히 삭제하여 4개 깔끔한 레이어로 정돈.
- **기호 및 따옴표 콤보/Shift 쌍 관리**:
  - **백틱(` ` `) & 틸드(`~`)**: `_NUM` 레이어 왼쪽 안쪽 열 상단 (`KC_GRV`, Shift 누르면 `~`)
  - **작은따옴표(`'`) & 큰따옴표(`"`)**: `_NUM` 레이어 왼쪽 안쪽 열 중단 (`KC_QUOT`, Shift 누르면 `"`)
  - **중괄호(`{`, `}`)**: `_NUM` 레이어 오른쪽 안쪽 열 상단 및 중단 (`KC_LCBR` / `KC_RCBR`)
- **한영/한자 및 모디파이어 이동**:
  - **한/영 전환 (`KC_RALT`)**: `_NAV` 레이어 오른쪽 엄지 중간 키로 이동.
  - **한자 변환 (`KC_RCTL`)**: `_NAV` 레이어 오른쪽 엄지 바깥 키로 이동.
  - **`ESC`**: `SPC_NAV` + `Q` 조합으로 사용.
  - **`BSPC`**: `SPC_NAV` + `V` 조합으로 사용.

## 💡 Notes
- 분할 키보드 통신을 위해 `MASTER_LEFT`가 설정되어 있으므로, 반드시 **왼쪽 키보드**를 컴퓨터에 USB로 연결하여 사용하십시오.
- TRRS 케이블 연결 시 반드시 전원을 끄고 연결하십시오.
