# ⌨️ Corne v4.1 (46-key) QMK Custom Configuration

이 프로젝트는 **Corne v4.1 (RP2040)** 분할 키보드를 위한 커스텀 QMK 펌웨어 설정 저장소입니다. 기존 설정을 최적화하여 완벽한 좌우 대칭 엄지 모디파이어 구조와 효율적인 4레이어(RAW 제외) 구성을 구현했습니다.

## 🛠 Hardware Info
- **Model:** Corne v4.1 (Standard, 46-key version)
- **MCU:** RP2040 (Integrated)
- **Layout:** 3x6_3 with 2 extra inner keys per side (`LAYOUT_split_3x6_3_ex2`)

## ⌨️ Visual Layout

### 1. Default Layer (`_DEFAULT`)
기본 타이핑 레이어입니다. 엄지 라인은 [Num/Sym - Navi - Func] 구조로 직관적인 완벽 대칭을 이룹니다. 알파 키들의 레이어 모디파이어 기능을 완전히 빼고 일반 키로 환원하여 타이핑 반응 속도를 최적화했습니다. 검지 확장 스트레칭 방지를 위해 왼손 안쪽 열(7번째 열)은 비워두어 인체공학적 효율성을 높였습니다.

```text
┌───────┬───────┬───────┬───────┬───────┬───────┬───────┐       ┌───────┬───────┬───────┬───────┬───────┬───────┬───────┐
│  ESC  │   Q   │   W   │   E   │   R   │   T   │       │       │  DEL  │   Y   │   U   │   I   │   O   │   P   │ BSPC  │
├───────┼───────┼───────┼───────┼───────┼───────┼───────┤       ├───────┼───────┼───────┼───────┼───────┼───────┼───────┤
│ LCTL  │ A(G)  │ S(A)  │ D(C)  │ F(S)  │   G   │       │       │ TG(R) │   H   │ J(S)  │ K(C)  │ L(A)  │ ;(G)  │   '   │
├───────┼───────┼───────┼───────┼───────┼───────┼───────┘       └───────┼───────┼───────┼───────┼───────┼───────┼───────┤
│ LSFT  │   Z   │   X   │   C   │   V   │   B   │                       │   N   │   M   │   ,   │   .   │   /   │ RSFT  │
└───────┴───────┴───────┼───────┼───────┼───────┤                       ├───────┼───────┼───────┼───────┴───────┴───────┘
                        │  Num  │  Nav  │ TAB(F)│                       │ ENT(F)│ SPC(N)│  Num  │
                        └───────┴───────┴───────┘                       └───────┴───────┴───────┘
```
*(G=GUI, A=Alt, C=Ctrl, S=Shift, TG(R)=RAW Toggle, Num=Number & Symbol Layer, Nav=Navigation Layer, TAB(F)=Tab hold for Func, ENT(F)=Enter hold for Func, SPC(N)=Space hold for Navi)*

### 2. Navigation Layer (`_NAV`)
방향키와 마우스 제어 레이어입니다. (**양쪽 엄지 가운데** 키 홀드 시 진입)

```text
┌───────┬───────┬───────┬───────┬───────┬───────┬───────┐       ┌───────┬───────┬───────┬───────┬───────┬───────┬───────┐
│       │  ACL0 │ WH_L  │ WH_D  │ WH_U  │ WH_R  │       │       │       │ HOME  │ PGUP  │ PGDN  │  END  │       │       │
├───────┼───────┼───────┼───────┼───────┼───────┼───────┤       ├───────┼───────┼───────┼───────┼───────┼───────┼───────┤
│       │  ACL2 │ MS_L  │ MS_D  │ MS_U  │ MS_R  │       │       │       │ LEFT  │ DOWN  │  UP   │ RGHT  │       │       │
├───────┼───────┼───────┼───────┼───────┼───────┼───────┘       └───────┼───────┼───────┼───────┼───────┼───────┼───────┤
│       │       │ BTN1  │ BTN3  │ BTN2  │       │                       │       │ BSPC  │  DEL  │       │       │       │
└───────┴───────┴───────┼───────┼───────┼───────┤                       ├───────┼───────┼───────┼───────┴───────┴───────┘
                        │       │       │       │                       │       │       │       │
                        └───────┴───────┴───────┘                       └───────┴───────┴───────┘
```
*(ACL0/2=마우스 가속 속도 0/2, WH_L/D/U/R=마우스 휠 좌/하/상/우, MS_L/D/U/R=마우스 커서 이동 좌/하/상/우, BTN1/3/2=마우스 좌클릭/휠클릭/우클릭, BSPC=Backspace, DEL=Delete)*

### 3. Number & Symbol Layer (`_NUM`)
숫자 입력 및 특수 기호 통합 레이어입니다. (**양쪽 엄지 가장 바깥쪽** 키 홀드 시 진입)
왼손 아랫줄에 직관적인 괄호 고속도로(`[ ] ( ) \` on `Z, X, C, V, B`)를 구축했습니다. 오른손으로 `MO(_NUM)`을 누른 상태에서 왼손이 놀지 않도록 **왼손 엄지 3개 영역에 `_`, `+`, `|` 기호를 배치**하여 타건 효율성을 극대화했습니다. 오른손 영역은 표준 텐키 패드입니다.

```text
┌───────┬───────┬───────┬───────┬───────┬───────┬───────┐       ┌───────┬───────┬───────┬───────┬───────┬───────┬───────┐
│   `   │   !   │   @   │   #   │   $   │   %   │       │       │       │   /   │   7   │   8   │   9   │   -   │       │
├───────┼───────┼───────┼───────┼───────┼───────┼───────┤       ├───────┼───────┼───────┼───────┼───────┼───────┼───────┤
│       │   ^   │   &   │   *   │   -   │   =   │       │       │       │   *   │   4   │   5   │   6   │   +   │       │
├───────┼───────┼───────┼───────┼───────┼───────┼───────┘       └───────┼───────┼───────┼───────┼───────┼───────┼───────┤
│ LSFT  │   [   │   ]   │   (   │   )   │   \   │                       │       │   1   │   2   │   3   │   .   │       │
└───────┴───────┴───────┼───────┼───────┼───────┤                       ├───────┼───────┼───────┼───────┴───────┴───────┘
                        │   _   │   +   │   |   │                       │       │   0   │       │
                        └───────┴───────┴───────┘                       └───────┴───────┴───────┘
```

### 4. Function Layer (`_FUNC`)
기능 키 레이어입니다. (**양쪽 엄지 가장 안쪽** 키 홀드 시 진입, 탭 시 원래 키 기능 수행)
인지 부하를 줄이기 위해 왼손과 오른손에 `F1`~`F12` 기능 키를 완벽 대칭 거울상(Mirroring) 구조로 배치했습니다. 단, 왼손 새끼손가락의 중요 탭 키인 `TAB` 기능은 그대로 유지하여 타건 효율성을 보존했습니다.

```text
┌───────┬───────┬───────┬───────┬───────┬───────┬───────┐       ┌───────┬───────┬───────┬───────┬───────┬───────┬───────┐
│       │  TAB  │  F9   │  F8   │  F7   │  F12  │       │       │       │  F12  │  F7   │  F8   │  F9   │       │       │
├───────┼───────┼───────┼───────┼───────┼───────┼───────┤       ├───────┼───────┼───────┼───────┼───────┼───────┼───────┤
│       │       │  F6   │  F5   │  F4   │  F11  │       │       │       │  F11  │  F4   │  F5   │  F6   │       │       │
├───────┼───────┼───────┼───────┼───────┼───────┼───────┘       └───────┼───────┼───────┼───────┼───────┼───────┼───────┤
│       │       │  F3   │  F2   │  F1   │  F10  │                       │  F10  │  F1   │  F2   │  F3   │       │       │
└───────┴───────┴───────┼───────┼───────┼───────┤                       ├───────┼───────┼───────┼───────┴───────┴───────┘
                        │       │       │       │                       │       │       │       │
                        └───────┴───────┴───────┘                       └───────┴───────┴───────┘
```

### 5. RAW Layer (`_RAW`)
홈로우 모드가 일시 정지된 일반 키보드 레이어입니다. 게임 실행이나 빠른 연속 타이핑 등 단일 키 입력 처리가 요구될 때 유용합니다. (`TG(_RAW)` 키로 토글하여 활성화/비활성화)

```text
┌───────┬───────┬───────┬───────┬───────┬───────┬───────┐       ┌───────┬───────┬───────┬───────┬───────┬───────┬───────┐
│  ESC  │   Q   │   W   │   E   │   R   │   T   │  ENT  │       │  DEL  │   Y   │   U   │   I   │   O   │   P   │ BSPC  │
├───────┼───────┼───────┼───────┼───────┼───────┼───────┤       ├───────┼───────┼───────┼───────┼───────┼───────┼───────┤
│ LCTL  │   A   │   S   │   D   │   F   │   G   │  TAB  │       │ TG(R) │   H   │   J   │   K   │   L   │   ;   │   '   │
├───────┼───────┼───────┼───────┼───────┼───────┼───────┘       └───────┼───────┼───────┼───────┼───────┼───────┼───────┤
│ LSFT  │   Z   │   X   │   C   │   V   │   B   │                       │   N   │   M   │   ,   │   .   │   /   │ RSFT  │
└───────┴───────┴───────┼───────┼───────┼───────┤                       ├───────┼───────┼───────┼───────┴───────┴───────┘
                        │ LALT  │ LGUI  │  TAB  │                       │  ENT  │  SPC  │ RALT  │
                        └───────┴───────┴───────┘                       └───────┴───────┴───────┘
```

## 🚀 Quick Start (NixOS)

### 1. 동기화 (최초 1회 실행)
저장소의 설정을 `qmk_firmware` 폴더 내의 Corne 키맵 위치로 심볼릭 링크를 설정합니다.

```bash
# 기존 디렉토리가 존재한다면 삭제 (또는 백업)
rm -rf ~/qmk_firmware/keyboards/crkbd/keymaps/yongminari

# 올바른 경로로 심볼릭 링크 설정
ln -s /home/yongminari/Workspace/qmk_split_keymap/keymaps/yongminari ~/qmk_firmware/keyboards/crkbd/keymaps/yongminari
```

### 2. Build (펌웨어 컴파일)
저장소 루트의 빌드 헬퍼 스크립트를 사용하여 펌웨어를 빌드합니다.

```bash
qmk compile -kb crkbd/rev4_1/standard -km yongminari --clean
```

### 3. Flash (펌웨어 다운로드)
스플릿 키보드의 부트로더 모드(RPI-RP2)에 각각 연결한 뒤 플래시 헬퍼 스크립트를 사용하여 양쪽에 펌웨어를 다운로드합니다.
- **부트로더 진입 방법:**
  - **왼쪽:** `Q` 키를 누른 채 USB 연결
  - **오른쪽:** `P` 키를 누른 채 USB 연결

```bash
# 장치 이름(sdX1 등)은 lsblk 명령어는 필수 확인
sudo dd if=/home/yongminari/qmk_firmware/crkbd_rev4_1_standard_yongminari.uf2 of=/dev/sdX1 conv=fdatasync status=progress
```

## ⌨️ Keymap Features
- **Home Row Mods (GACS):** `A,S,D,F / J,K,L,;` 키에 GUI, Alt, Ctrl, Shift 적용.
- **Tapping Term:** 180ms 일괄 적용.
- **Tapping Optimizations:** 오작동 방지를 위해 `HOLD_ON_OTHER_KEY_PRESS` 및 `PERMISSIVE_HOLD` 제거.
- **Caps Word 더블탭 기능:** 외각 핑크색 전용 Shift 키(`KC_LSFT` / `KC_RSFT`)를 빠르게 **더블 탭**하여 Caps Word 상태를 즉시 활성화할 수 있습니다. (홈로우 모디파이어인 `F_SFT` / `J_SFT`는 한글 타건 시 오동작 방지를 위해 제외)
- **Layers:**
  - `_DEFAULT`: 기본 알파 및 Home Row Mods, 대칭형 엄지 레이아웃 구조.
  - `_NAV`: 방향키, 마우스 제어. **양쪽 엄지 가운데 키**(`MO(_NAV)` / `LT(_NAV, KC_SPC)`) 홀드로 진입.
  - `_NUM`: 통합 숫자 & 특수 기호 레이어. **양쪽 엄지 가장 바깥쪽 키**(`MO(_NUM)`) 홀드로 진입.
  - `_FUNC`: F1 ~ F12 기능 키 및 Tab/Enter 입력. **양쪽 엄지 가장 안쪽 키**(`LT(_FUNC, KC_TAB)` / `LT(_FUNC, KC_ENT)`) 홀드로 진입.
  - `_RAW`: 홈로우 정지 모드 (오른쪽 검지 안쪽 키로 토글).
- **Key Position Changes for Optimization (인체공학 및 타이핑 효율성 극대화):**
  - **알파 키 딜레이 원복 (`V`, `N`, `G`, `Comma`)**: 모든 알파 키들의 레이어 모디파이어 기능을 완전히 제거하여 일반 키로 지정, 고속 타이핑 시 딜레이와 오작동 원천 방지.
  - **대칭형 엄지 레이아웃 최적화**:
    - **가장 바깥쪽 (Outer)**: `Num/Sym` 통합 모디파이어 (`MO(_NUM)`)
    - **가운데 (Middle)**: `Navi` 모디파이어 (`MO(_NAV)` / `LT(_NAV, KC_SPC)`)
    - **가장 안쪽 (Inner)**: `Func` 모디파이어 (`LT(_FUNC, KC_TAB)` / `LT(_FUNC, KC_ENT)`)
  - **기호 및 괄호 최적 배치 ("Shift-Pair Standard Optimization")**:
    - `[]`, `()`, `\` 괄호 고속도로: 왼손 아랫줄 `Z, X, C, V, B` 위치에 `[`, `]`, `(`, `)`, `\`를 나란히 배치하여, 기존 12개 기호를 Standard Shift 조합(예: `Shift + [` -> `{`) 단 6개의 키로 완벽하게 대응하고, 손목과 인지 피로를 최소화했습니다.
    - ``` ` ``` 백틱: 왼쪽 판 가장 바깥쪽 최상단(ESC 자리)에 배치.
    - **왼손 엄지 기호 배치 (`_`, `+`, `|`)**: 오른손의 `_NUM` 모디파이어 키를 눌러 진입할 때, 왼손 엄지의 세 개 키가 `_` (Underscore), `+` (Plus), `|` (Vertical Pipe)를 입력할 수 있도록 매핑하여 키 입력 효율과 연계성을 향상했습니다.
  - **F-키 미러링 최적화**: `F1`~`F12`를 좌우 대칭으로 설계하여 인지 편의성을 개선하면서, 왼손 Q열의 `TAB` 기능을 온전히 지켜 기존 워크플로우와의 하방 호환성을 유지했습니다.
