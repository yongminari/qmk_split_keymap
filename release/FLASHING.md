# Corne v4.1 펌웨어 플래싱

이 패키지의 `flash.sh`는 Linux용 도우미입니다. Windows와 macOS에서는 릴리스의 UF2 파일을 `RPI-RP2` 드라이브로 직접 복사하면 됩니다.

1. 키보드의 USB와 TRRS 케이블을 모두 분리합니다.
2. 왼쪽은 `Q`, 오른쪽은 `P` 키를 누른 채 USB를 연결해 `RPI-RP2` 부트로더로 진입합니다.
3. 자동 마운트된 Linux 환경에서는 아래 명령을 실행합니다.

   ```bash
   ./flash.sh
   ```

4. 자동 감지가 되지 않거나 아직 마운트되지 않았다면 장치 이름을 지정합니다. 스크립트가 `RPI-RP2` 볼륨인지 확인하고 자동으로 마운트합니다.

   ```bash
   ./flash.sh sdc1
   ```

5. 전체 장치 경로나 마운트 경로를 직접 지정할 수도 있습니다.

   ```bash
   ./flash.sh /dev/sdc1
   ./flash.sh /run/media/$USER/RPI-RP2
   ```

6. 왼쪽과 오른쪽에 각각 같은 절차로 펌웨어를 설치합니다.

스크립트는 `INFO_UF2.TXT`가 있는 RP2040 부트로더 볼륨만 허용하며, 블록 장치에 `dd`를 실행하지 않습니다.
